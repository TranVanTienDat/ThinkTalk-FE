# Figma Audit & V2 Evolution Skill

This skill provides a systematic framework for auditing an implementation against a Figma design and planning a "Version 2" that moves from MVP to a Premium experience.

## 1. Strict Audit Framework (The Deep Audit)

When asked to "check" or "review" against Figma, perform a **Comparative Audit** using this checklist:

### A. The "Pixel-Perfect" Checklist

- **Shadow Depth**: Does the shadow match the Figma "softness"? (Check `rgba` opacity and `blur` radius. Multi-layer shadows are preferred for high-end UI).
- **Typography Alignment**:
  - Check for **Italic vs Normal** text styles.
  - Verify **Rating positioning** (e.g., top-right corners vs inline).
  - Match `line-height` exactly (important for body text readability).
- **Border & Stroke**:
  - Check `border-width` (1px vs 2px).
  - Match `border-color` in both default and hover states.
- **Spacing Pulse**:
  - Measure **Gaps** in grids/flexboxes specifically (e.g., 50px between testimonial cards).
  - Verify **Section Overlaps** (e.g., Use negative margins or absolute positioning for overlapping cards).

### B. Layout & Flow Audit

- **Navigation Controls**: Check relative positions (e.g., Are dots on the left and arrows on the right?).
- **Footer Integrity**:
  - Is the Footer CTA card correctly positioned on the section boundary?
  - Are the grid columns balanced with correct max-widths?
- **Responsive Scalability**: Check how `aspect-ratio` and `object-fit` behave when the screen shrinks.

## 2. Version 2 (V2) Premium Strategy

Upgrade from "Functional" to "Wowed" using these pillars:

### A. Advanced Micro-interactions

- **Staggered Sequences**: Use `framer-motion` to stagger the entrance of list items or grid cards.
- **Interactive States**: Add scale effects (`scale-105`), deep shadow transitions, or border-color shifts on hover.
- **Global Theme Details**: Implement `selection:bg-[#...]` for brand-consistent text highlighting.

### B. Optimization & Refinement

- **Asset Strategy**: Replace emojis with high-quality PNGs/SVGs. Optimize with `next/image` (`priority`, `fill`, `sizes`).
- **Semantic Structure**: Ensure correct HTML5 tags (`<main>`, `<section>`, `<header>`, `<footer>`).

## 3. Workflow Procedure

1. **Pulse**: Read Figma data.
2. **Scan**: Look at the current TSX files.
3. **Audit Table**: Create a table of "Current Implementation" vs "Figma Intent".
4. **Fix Strategy**: Fix immediate layout/spacing errors.
5. **V2 Roadmap**: Propose animations and premium refinements.
